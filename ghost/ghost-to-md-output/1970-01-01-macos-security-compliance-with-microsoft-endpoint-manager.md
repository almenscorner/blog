If you're in charge of managing macOS devices for your organisation, you know how hard it can be to keep up with changes that come with each new OS release to stay secure. For a while now we've had security baselines in MEM for Windows, Office and Edge, these are pre-configured profiles that contains hundreds of recommended  security related settings to help you quickly get going. Most recently we also got baselines for iOS/iPadOS in MEM.

What about macOS?

While we do not have any built in baselines for macOS in MEM, there is an open source project called macOS Security Compliance.
